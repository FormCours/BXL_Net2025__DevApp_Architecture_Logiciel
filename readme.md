## Pattern
Les pattern de programmation permettre de solutionner des problematiques.  
→ Si vous n'avez pas le probleme, n'utiliser pas le pattern :p

Documentation : https://refactoring.guru/fr/design-patterns

**Différents types** :
- [Pattern d'architecture](./pattern_architecture.md) : _Structure des fichiers de l'application_
- Pattern de création : _Facilité l'instanciation d'element_
- Pattern comportementaux: _Pour de l'algorithmie et responsabilités des éléments_
- Pattern structurels: _Aide à la conception de la structure_
